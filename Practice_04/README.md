# Практика №4

## Краткое описание

Работа с таблицей продаж автомобилей в Pandas

В ноутбуке проверяются пропуски, считаются средние значения, находятся самые дорогие марки и выводятся покупки клиентов с самым высоким и самым низким доходом
В конце добавляется столбец с логарифмом годового дохода

## Структура

| Файл | Назначение |
|---|---|
| `practice_04.ipynb` | Условия заданий, код и результаты |
| `car_data.csv` | Исходные данные о продажах |

## Как запустить

1. Откройте папку `Practice_04` в VS Code
2. Проверьте, что `car_data.csv` лежит рядом с ноутбуком
3. Если библиотеки ещё не установлены, выполните в терминале

   ```powershell
   python -m pip install pandas numpy ipykernel
   ```

4. Откройте `practice_04.ipynb`, выберите ядро Python с установленными библиотеками и нажмите **Run All**
