## Справка по заданиям

### Задание 1: Високосный год
Определение, является ли год високосным по григорианскому календарю.

### Задание 2: Число знаков в десятичной записи
Нахождение количества цифр в натуральном числе (два решения).

### Задание 3: Сумма факториалов
Вычисление суммы 1! + 2! + 3! + ... + n! (два решения, один цикл).

### Задание 4: Проверка палиндрома
Определение, является ли строка палиндромом (три решения).

### Задание 5: Частота слов
Подсчёт частоты слов в тексте (два решения).

### Задание 6: Поиск символа в строке
Нахождение первого и последнего вхождения символа (один проход).

### Задание 7: Обработка списка чисел
Удаление отрицательных чисел, возведение в квадрат, сортировка (три решения).

### Задание 8: Сортировка кортежей
Сортировка списка кортежей по указанному индексу с возвратом генератора.

### Задание 9: Треугольник Паскаля
Вывод первых n строк треугольника Паскаля.

### Задание 10: Переименование файлов
Изменение расширения файлов в директории.

### Задание 11: Разность списков
Нахождение уникальных элементов первого списка, отсутствующих во втором (без циклов).

### Задание 12: Обработка файла с числами
Обработка числового файла с требованием O(1) по памяти.

### Задание 13: Генератор чисел Фибоначчи
Реализация конечного и бесконечного генератора чисел Фибоначчи.

### Задание 14: Магические методы объекта
Получение списка методов объекта в зависимости от типа (без циклов).

### Задание 15: ASCII-коды и split
Замена заглавных букв на ASCII-коды и разбиение по минимальной цифре (два решения).

### Задание 16: Извлечение телефонных номеров
Извлечение мобильных номеров с поддержкой 10+ форматов (регулярные выражения).

### Задание 17: Бинарное дерево
Обход бинарного дерева в глубину с вычислением сумм (рекурсия и итерация).
