# Лабораторная работа №3

## Краткое описание

Приложение на PySide6 прогнозирует возврат кредита или дефолт по семи признакам из датасета кредитного скоринга лабораторной №2

В окне можно выбрать логистическую регрессию или MLP  
Расчёт выполняется в отдельном потоке, поэтому окно остаётся отзывчивым  
Прогресс-бар показывает вероятность класса, который выбрала модель

## Структура проекта

| Файл или папка | Назначение |
|---|---|
| `main.py` | Запуск приложения |
| `desktop/` | Окно, фоновый поток и сигналы |
| `desktop/credit_window.ui` | Форма окна, собранная в Qt Designer |
| `services/` | Проверка введённой строки и подготовка результата |
| `ml/` | Загрузка модели и предсказание |
| `models/` | Две обученные модели в формате joblib |
| `data/credit.csv` | Синтетические данные из лабораторной №2 |
| `train_models.py` | Обучение и сохранение моделей |
| `requirements.txt` | Версии библиотек |
| `lab03_report.docx` | Отчёт со скриншотами |

## Как запустить

Откройте папку `Lab_03` в VS Code  
Для установки с нуля нужен Python 3.12

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Если папка `.venv` уже есть и библиотеки установлены, достаточно последней команды

Форму можно открыть в Qt Designer из папки `Lab_03`

```powershell
.\.venv\Scripts\pyside6-designer.exe .\desktop\credit_window.ui
```

Модели уже сохранены в папке `models`  
Если нужно обучить их заново, запустите

```powershell
.\.venv\Scripts\python.exe train_models.py
```

## Проверка

1. Введите `24, 25057, 14633, 48, 5, 0, 17` и нажмите **Предсказать**
2. Выберите другую модель и повторите предсказание
3. Проверьте, что при вводе `abc`, строки `1, 2` и при пустом поле появляется сообщение об ошибке
4. Нажмите **Очистить**, чтобы сбросить ввод и результат
