# Практика №2

## Краткое описание

Проект представляет собой консольную пошаговую стратегию **«Тени пустошей»**, разработанную на языке Python с применением принципов объектно-ориентированного программирования (ООП).

Действие игры происходит в постапокалиптическом мире, населённом зомби. Игрок управляет убежищем и отрядом выживших, исследует территорию, собирает ресурсы и сражается с противниками.

**Цель игры:** уничтожить всех зомби, сохранив убежище и хотя бы одного выжившего.

### Что реализовано:
- Игровое поле размером 20×20 клеток со случайной генерацией местности
- Шесть классов выживших с индивидуальными характеристиками и способностями
- Пошаговое перемещение персонажей и система боя
- Автоматическое поведение зомби (поиск целей, перемещение, атака)
- Три типа местности: дорога, лес и радиационная зона
- Предметы: аптечки, припасы, ловушки и бронежилеты
- Туман войны, ограниченная видимость и исследование территории
- Система ресурсов, создание и расформирование юнитов
- Лечение союзников и восстановление прочности убежища
- Цветной интерфейс и случайные реплики персонажей
- Игровая статистика, условия победы и поражения

### Реализованные принципы ООП:
- **Наследование** — иерархия классов юнитов, противников и игровых объектов
- **Полиморфизм** — переопределение методов и реализация уникальных способностей
- **Инкапсуляция** — объединение характеристик и поведения объектов внутри классов
- **Перегрузка операторов** — использование оператора `+` для взаимодействия юнитов с предметами
- **Композиция** — объединение игровых компонентов в классе `Game`

## Инструкции по запуску

### Запуск через BAT-файл (Windows)

1. Скачайте папку `practice_02` с файлами проекта.
2. Убедитесь, что на компьютере установлен Python 3.
3. Запустите файл `start_game.bat` двойным нажатием.
4. Ознакомьтесь со вступлением и правилами игры.
5. Для управления используйте числовое меню и ввод координат.

### Запуск через Visual Studio Code

1. Откройте папку `practice_02` в Visual Studio Code.
2. Откройте файл `main.py`.
3. Запустите программу через терминал:
   ```bash
   python main.py
   ```
4. Следуйте инструкциям игрового меню.

## Справка по пунктам меню

### 1. Управление убежищем

Позволяет просматривать состояние убежища, создавать и расформировывать юнитов.

- **1. Состояние убежища** — выводит здоровье убежища, количество выживших и запас ресурсов.
- **2. Создать юнита** — позволяет выбрать класс персонажа и разместить его на свободной соседней клетке. Создание требует ресурсов.
- **3. Расформировать юнита** — удаляет выбранного персонажа из отряда.
- **0. Назад** — возвращает в главное меню.

### 2. Управление юнитами

Позволяет выбрать одного из выживших и выполнить действие.

- **1. Перемещение** — перемещает персонажа на выбранную клетку в пределах допустимой дальности.
- **2. Атака** — наносит урон зомби с учётом дальности атаки и брони противника.
- **3. Способность** — использует уникальную способность выбранного класса.
- **0. Назад** — возвращает в главное меню.

### 3. Обозначения

Выводит легенду игровой карты: символы персонажей, зомби, убежища, разновидностей местности и предметов.

### 0. Выход

Завершает игру.

## Классы персонажей

### 1. Штурмовик

Боевой юнит с высоким запасом здоровья и брони. Может выполнять усиленную атаку по соседнему противнику, расходуя ресурсы убежища.

### 2. Снайпер

Боевой юнит с повышенным уроном и дальностью атаки до 3 клеток. Может использовать усиленный выстрел.

### 3. Разведчик

Обладает увеличенным радиусом обзора (4 клетки), может перемещаться на 2 клетки по прямой. Активная способность позволяет определять типы предметов в радиусе 3 клеток.

### 4. Дозорный

Обладает увеличенным радиусом обзора (4 клетки) и пониженной восприимчивостью к радиации. Может исследовать местность в радиусе 6 клеток.

### 5. Медик

Юнит поддержки, способный восстанавливать здоровье союзников на соседних клетках.

### 6. Инженер

Юнит поддержки, способный ремонтировать убежище, находясь рядом с ним.

## Особенности игрового процесса

### Исследование карты

Неисследованные клетки скрыты туманом войны. При перемещении персонажей новые территории становятся доступными для просмотра. Ранее исследованные области сохраняются на карте, но объекты за пределами текущей видимости не отображаются.

### Ландшафт и предметы

- **Дорога** — обычная территория без дополнительных эффектов.
- **Лес** — временно увеличивает броню персонажа на 10 единиц.
- **Радиация** — наносит урон при входе на клетку.
- **Аптечка** — восстанавливает здоровье.
- **Припасы** — пополняют ресурсы убежища.
- **Ловушка** — наносит урон персонажу.
- **Бронежилет** — увеличивает броню персонажа.

### Ходы противников

После успешного действия игрока зомби выполняют свой ход: перемещаются по игровому полю, обнаруживают ближайшие цели и атакуют выживших или убежище.

### Завершение игры

- **Победа** — уничтожены все зомби.
- **Поражение** — разрушено убежище или погибли все выжившие.

После завершения выводится итоговая статистика: количество ходов, уничтоженных зомби, оставшихся выживших, ресурсов и исследованной территории.
