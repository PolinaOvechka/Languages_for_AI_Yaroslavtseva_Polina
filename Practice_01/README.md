#  Практика №1 — Контекстное меню (Вариант 21)

## Краткое описание

Проект представляет собой интерактивное **контекстное меню** на языке Python, объединяющее 12 учебных заданий по основам программирования. Меню позволяет пользователю в интерактивном режиме выбирать и запускать отдельные блоки кода, демонстрирующие работу с различными типами данных и стандартными возможностями Python.

### Что реализовано:
- Работа со строками (срезы, конкатенация, замена символов)
- Работа со списками (срезы, копирование)
- Работа со словарями (добавление, обновление)
- Работа с множествами
- Чтение и запись текстовых файлов
- Сериализация и десериализация данных (`pickle`, `json`)
- Проверка версии интерпретатора Python

## Справка по пунктам меню
1. Проверка выражения 0
Выполняет срезы строк "agility"[2:5] + "taxonomy"[3:6] и выводит результат.
2. Проверка выражения 4
Определяет тип данных результата среза списка [False, True, False, True][2:3].
3. Замена символов (фиксированная)
Заменяет все вхождения буквы "l" на "s" в строке "Hello World!" с помощью метода .replace(). Результат: "Hesso Worsd!".
4. Замена символов (через input)
Пользователь сам вводит символ, который нужно заменить на "s" в строке "Hello World!".
5. Копирование списка (.copy)
Создаёт копию списка ["яблоко", "программа", "космос", "гитара", "дождь", "зеркало", "синтезатор"] с помощью метода .copy(). 
6. Копирование списка (срез [:])
Создаёт копию того же списка с помощью полного среза [:]. Альтернативный способ копирования списков в Python.
7. Добавление элементов в словарь
Добавляет новые пары ключ-значение в словарь {0: 10, 1: 20}. Добавляются ключи 4, 5, 6 со значениями 16, 8, 9 соответственно.
8. Обновление словаря (.update)
Объединяет два словаря {0: 10, 1: 20} и {2: 3, 3: 15, 4: 67} с помощью метода .update().
9. Преобразование списка в множество
Удаляет дубликаты из списка ['рука', 'голова', 'нога', 'рука', 'нога', 'живот'] через преобразование в множество set(). Результат содержит только уникальные элементы.
10. Работа с текстовым файлом
Создаёт файл example.txt, записывает в него 10 строк ("Строка номер 1" ... "Строка номер 10"), выводит всё содержимое файла и последние 3 строки. 
11. Сериализация через pickle
Сохраняет словарь {'имя': 'Полина', 'возраст': 25, 'образование': 'ТвГТУ'} в бинарный файл data.pkl с помощью модуля pickle, затем загружает его обратно.
12. Сериализация через json
Сохраняет тот же словарь в текстовый файл data.json с помощью модуля json, затем загружает его обратно.
0. Выход
Завершает работу программы и выходит из цикла меню.
